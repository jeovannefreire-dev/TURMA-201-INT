# Portfólio — Turma 201 INT

Projeto-base para os alunos da Turma 201 INT — Informática para Internet.

## Como executar
1. Baixe e extraia o ZIP.
2. Abra a pasta no Visual Studio Code.
3. Abra `index.html`.
4. Execute com o **Live Server**.

## Personalização
Cada aluno deve substituir:
- `SEU NOME`
- `SUA FOTO`
- texto de Sobre Mim
- habilidades
- projetos
- formação
- e-mail, GitHub e LinkedIn

A pasta `images` contém uma imagem de exemplo para o projeto. O aluno pode substituí-la por suas próprias imagens.

## Estrutura
- `index.html` — estrutura do site
- `style.css` — visual e responsividade
- `script.js` — menu mobile
- `images/` — imagens dos projetos
- `README.md` — orientações
